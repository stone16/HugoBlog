The reframe

Three of the four things you proposed are infrastructure. But the credibility problem is editorial hierarchy plus a review gate. The rewrite is still worth doing — it is what makes the admin, the artifacts and first-party comments possible — but it is not, by itself, the fix.

02

The twelve decisions

Each was chosen against a named constraint that ruled out the alternatives. Nine are recorded as ADRs in docs/adr/, currently status: proposed — they flip to accepted on your confirmation.

D01

D1 is the sole source of truth for Posts

No git mirror. Keeping git authoritative would mean rewriting the posts module, editor and taxonomy of the very template adopted to avoid that work. Time Travel gives 30-day restore.

ADR-0001
D02

Revisions are mandatory, not optional

Leaving git forfeits diff review of what was published. Every write appends a revision row; the editor shows a diff and restores in one click.

ADR-0001 · consequence
D03

One Locale per Post, optional Translation Group

Full parity was rejected: it makes every post a permanent 2× writing commitment, and thin machine translation is a negative quality signal on an authority play.

ADR-0002
D04

Artifacts at <slug>.stometa.dev

Brand coherence chosen over the stronger isolation a second registrable domain would give. Defensible only with the four browser-enforced controls in section 04.

ADR-0003
D05

First-party Comments replace Giscus

Anonymous + Turnstile; first comment held, then the commenter is trusted. Turnstile over reCAPTCHA because it is reachable from mainland China. Nothing to migrate.

ADR-0004
D06

Address decoupled from access

A memorable Slug is a guessable Slug, so the name can't be the lock. visibility changes freely without breaking a sent link. Defaults to password + noindex.

ADR-0005
D07

Hard fork of ShipAny, no upstream

~60% of the template is SaaS machinery a blog never runs. The first schema change touches posts — the table upstream owns — so every future merge conflicts for no benefit.

ADR-0006
D08

Nexus is retired; posts are hand-written

The requirement was “in my own words.” The autonomous publisher is the mechanism that produced the quality being fixed. Silence, not bad writing, is this decision's failure mode.

ADR-0007
D09

Markdown storage; rich mode must prove itself

Both editors offered per post. Toggling to rich mode runs the round-trip and blocks unless the result is byte-identical, showing the diff it would have caused.

ADR-0008
D10

Chinese at the root, English at /en

Inverts the template default. Old paths survive byte-for-byte, so migration is one bulk 301 plus four hand rules — and the majority language gets the shortest URL.

ADR-0009 · consequence
D11

Editorial publication, not dark-gradient

“Authority” is what editorial design encodes. The DESIGN.md palette is retired — ShipAny's own design skill v2 commit literally reads “ban dark-gradient-glow cliches.”

—
D12

One cutover, behind continuous staging

Both costs of big-bang are structurally removed: Hugo keeps publishing throughout, and the finished app runs on a private staging host from week one.

04

The four controls that make D04 safe

You chose one brand domain over two registrable domains. That is a real trade, and it holds only because these are enforced by the browser rather than by remembering to be careful. Drop any one and the decision stops being defensible.

ControlWhy it cannot be quietly misconfigured
__Host- session cookie prefixBrowsers reject a __Host- cookie that carries a Domain attribute. Host-only scoping becomes structurally impossible to get wrong, rather than a config line someone edits later.
Origin allowlist on mutating routesThe Origin header is set by the browser and cannot be forged from script. One middleware rejecting anything ≠ https://stometa.dev closes the cross-subdomain request path outright.
connect-src 'self' CSP on artifactsLavish artifacts are self-contained by design, so this costs them nothing while blocking calls back to the apex API.
Reserved slug listwww · api · admin · mail · staging · _dmarc and friends must never be claimable, or an artifact can impersonate infrastructure.

Residual risk, stated plainly

Subdomains of stometa.dev are a different origin but the same site. Origin isolation stops DOM and localStorage access; it does not stop SameSite=Lax cookies riding along. The controls above are what close that gap. If you ever open artifact publishing to other people, revisit ADR-0003 before you do — not after.

07

Build order

You chose a single cutover. The Hugo site serves stometa.top untouched through every phase below, and the new app is deployed to a password-protected noindex staging host from phase 1 onward — so the cutover is a DNS change against a system that has been running for weeks, not a launch.

Phase 0 · Foundation

Domain and skeleton

  • Acquire stometa.dev, nameservers to Cloudflare, wildcard *.stometa.dev proxied
  • Fork ShipAny → stone16/stometa-dev; first commit deletes payment, credits, subscriptions, invite-codes, tickets, ai-tasks; drop the upstream remote
  • D1 + R2 provisioned, wrangler.jsonc from the example, pnpm cf:deploy proven end to end
  • staging.stometa.dev live, password-gated, noindex
Gate: a deployed page loads from D1 on the staging host
Phase 1 · Publication

Content, schema, editorial design

  • Schema: locale, translation_group_id, revisions, editor_mode
  • Invert locale routing — zh at root, /en prefixed; slugs preserved byte-for-byte
  • Import the 14 posts from content/posts/*.md with front-matter mapped to columns
  • Markdown editor + preview; rich mode behind the lossless round-trip gate
  • Editorial front page: featured slot, thematic shelves, excerpts, reading time, CJK type stack
  • RSS, sitemap, hreflang on Translation Group pairs
Gate: every existing URL resolves on staging; a post survives 5 saves byte-identical
Phase 2 · Conversation and sharing

Comments and artifacts

  • Comments: Turnstile, pending queue, trust-on-first-approval, admin reply
  • Artifacts: R2 upload via API key, visibility rule, update key, reserved-slug list
  • The four D04 controls — __Host- cookie, Origin allowlist, artifact CSP, reserved slugs
  • lavish-axi publishing target pointed at stometa.dev instead of ht-ml.app
Gate: an artifact on a subdomain provably cannot call an authenticated admin route
Phase 3 · Cutover

One move

  • Migrate any posts published to Hugo during the build
  • DNS: stometa.dev apex to the Worker
  • Bulk 301 stometa.top/* → stometa.dev/*, plus 4 hand rules for the English posts
  • Dedicated 301 for /index.xml with the feed's self-<link> updated — miss this and every RSS subscriber goes quiet without telling you
  • Re-point the GA4 data stream off stometa.top; submit the new sitemap to Search Console
  • Archive stone16/HugoBlog read-only
Gate: old deep links resolve, feed readers follow, analytics continuous across the boundary
08

What could go wrong

SeverityRiskMitigation, or the honest absence of one
High Silence. Nexus retired + a full rebuild = months of building and nothing published. The historical record is real: hand-written posts ran Mar–Apr 2025, then nothing until August, then nothing until Nexus started in Feb 2026. Hugo staying live is a capability, not a mitigation — it only helps if you use it. This one is on you, not the architecture.
Med Same-site subdomain lets artifact JS reach the admin API Fully closed by the four controls in section 04 — but only if all four ship. Treat them as one indivisible task.
Med Round-trip corruption via an accidental rich-mode toggle Blocked mechanically, not by discipline: the toggle refuses unless md → html → md′ is byte-identical. Revisions cover the residue.
Med SEO and subscriber loss at cutover Slugs preserved byte-for-byte, so one bulk rule carries the link equity. The genuinely easy-to-forget items are the feed 301 and the GA4 stream.
Low D1 loss takes years of writing with it Time Travel gives 30-day point-in-time restore and wrangler d1 export --remote dumps on demand. Worth wiring the export into CI anyway — it is one line.
Low Moderation queue becomes a chore you stop working Trust-on-first-approval means the queue shrinks as your real readership stabilises. If it still nags, that is a signal to revisit ADR-0004, not to leave comments pending forever.
09

Still open — seven things I need from you

These are genuinely unresolved — Q6 and Q7 are new, forced by the verification results above. Pick or type, then queue each answer; they come back to me as separate prompts so nothing gets lost.

Q1What makes you say, in six months, that this was worth it?

You never answered this one, and it is the only thing that tells us whether the plan succeeded. Every decision above optimises for something — I need to know for what.

Q6Turnstile is dead — what gates comments instead?

You chose “Anonymous + Turnstile, first comment moderated.” Cloudflare documents Turnstile as unsupported in Mainland China, so the half of that option doing the bot resistance does not work for your primary readership. The anonymous + moderation half is unaffected. This is a genuine re-decision, not a detail.

Q7Your flagship post is raw HTML with its own design system

The X-algorithm deep dive is 299 HTML tags with an inline <style> block, an in-body Google Fonts import, and its own palette (--primary:#ff385c). It works today only because Hugo runs with unsafe: true. It is simultaneously your best work, my proposed featured post, and the thing that will clash hardest with the new editorial design.

Q2Do you already own stometa.dev?

Phase 0 blocks on this, and .dev is on the HSTS preload list — it is HTTPS-only by force, so there is no http fallback to lean on during setup.

Q3How far does artifact hosting go in v1?

You said “an HTML, or a PDF.” Those are different products: HTML is a page you serve, PDF is a file a browser either renders inline or downloads. Retention matters too — without it you accumulate a sprawl of stale pages you forgot are public. Tick everything in scope.

Q4Which existing features survive the move?

The Hugo site has pieces the template has no equivalent for. Each is real work that nobody has budgeted, and dropping them silently is how a migration quietly loses things.

Q5What stops the silence?

This is the one risk with no architectural fix. You retired the pipeline that produced 12 of your last 16 posts, and the hand-written era has two multi-month gaps in it. I would rather design against this now than discover it in November.
